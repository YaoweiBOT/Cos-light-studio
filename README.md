# Cos Light Studio · 二次元人像布光练习室

[![Version](https://img.shields.io/badge/version-0.5.0-2f81f7)](RELEASE_NOTES_v0.5.0.md)
[![License](https://img.shields.io/badge/code-MIT-green)](LICENSE)
[![Runtime](https://img.shields.io/badge/runtime-local%20browser-orange)](#最快开始)

Cos Light Studio 是一个本地运行的三维摄影布光学习工具。它用面积光源、可调光束与 GPU 路径追踪，帮助摄影者观察面光、轮廓光、顶光、光源尺寸、距离、光比、色温和白平衡怎样改变人脸与全身人物的受光。

**当前稳定版：0.5.0。** `main` 保存完整源码和已经构建好的本地程序，可直接下载运行。公开仓库不包含受原作者条款限制的三个 MMD 角色；持有原模型 ZIP 的用户可以在本机导入，模型不会上传到任何服务。

**这是本地网页应用。** 浏览器负责界面和显卡渲染，本机小服务器负责读取随包文件。无需账号、API Key 或云端渲染服务。发布包包含完整源码、渲染库的构建结果、人脸模型和贴图；正常运行不向 CDN 下载依赖。

## 最快开始

1. 点击上方「下载当前版本 ZIP」，把 ZIP **完整解压到一个新文件夹**。不要在压缩包内直接运行，也不要单独打开 `index.html`。
2. 电脑有 **Python 3.8+ 或 Node.js 22.12+** 其中一个即可。开发和重新构建需要 Node.js；只使用发布包可以仅有 Python。
3. Windows 双击 **`start-windows.cmd`**。浏览器会打开 `http://127.0.0.1:5273/`，保留启动窗口。
4. 使用桌面 Chrome / Edge，开启浏览器硬件加速。首次进入会编译着色器，画面随后逐步收敛。

如果浏览器未自动打开，把上面的本机地址复制进去。按启动窗口中的 Ctrl+C 关闭服务。

macOS 在终端运行 `sh start-macos.command`；Linux 运行 `sh start-linux.sh`。
也可以手动启动：

```sh
python scripts/serve.py
# macOS / Linux 通常用 python3
```

Node.js 启动方式：

```sh
npm start
```

源码和预构建结果匹配时，`npm start` 直接离线启动；源码有变更时，它会准备开发依赖并重建，首次重建需要联网。Python 启动器只运行 `dist/` 中的构建结果。**修改源码后请先重新构建。** 两种启动方式使用相同默认地址，浏览器存档可以共用。

### 离线使用条件

发布 ZIP 已包含 JavaScript、随包模型、贴图和系统字体回退，不必运行 `npm install`。安装好一个启动运行时和浏览器后，可以断网使用。项目不会自动上传方案、渲染图或诊断信息。页面上的署名和帮助外链仅在你主动点击时访问外部网站。

浏览器需支持 **WebGL 2 和浮点颜色缓冲**；渲染速度取决于实际 GPU、驱动、浏览器及画质。这个版本没有 CPU 渲染后备实现，也没有包含 Python / Node.js / 浏览器安装程序。

### 菲涅尔：聚光不等于更硬

1. 选择「菲涅尔 · 聚光 / 泛光」预设，先锁定曝光和功率。
2. 把全角从 15° 改到 60°，观察照亮范围变大、中心照度降低。
3. 保持全角，只改变出光口直径，比较鼻影与物体投影的边缘。
4. 单独调整光束边缘过渡，观察光斑边界；它与物体投影的柔度不是同一个量。
5. 使用精细瞄准将光扫过脸或背景，结合 A/B 比较。

这个模型使用**有限出光口 + 平滑锥形配光**，保持理想远场总光通量；数值测光与渲染器使用同一配光。它没有追踪菲涅尔镜片、反射器与灯丝，也没有标定厂商聚焦效率、真实高斯光场或菲涅尔暗纹。真实附件的配光并不等同于这个简化模型。光束直径为外缘几何估计，cd／lx 均基于内部参考输出。

参考：[ARRI Orbiter Fresnel 官方说明](https://www.arri.com/en/lighting/led-spotlights/orbiter/accessories/optics/fresnel-lens)、[ARRI L-Series Plus](https://www.arri.com/en/lighting/led-spotlights/l-series-plus)。官方说明中的可调聚光／泛光用于理解实物特性，**不代表本项目复制了这些产品的精确光学表现**。

## 可以练什么

- 三盏独立的矩形／圆形面积灯或菲涅尔近似光束：位置、距离、高度、瞄准、旋转、宽高、相对功率、色温、绿洋红偏移。
- 灯体面积实际参与光线采样；光源的角尺寸改变阴影柔度。扩大柔光箱时保持总光通量，便于比较近距离照度与柔度的关系。
- 真实扫描人头，可转头、抬低头，支持白模、灰模、皮肤贴图；另有灰、白、金属材质球。
- 黑棚墙面、地面反射、可控环境光，以及白板、黑旗、银板和下方反光板。
- 45° 单灯、伦勃朗、蝴蝶光、分割光、轮廓光等预设，俯视图可拖动灯位。
- 焦距、传感器、光圈、ISO、快门、曝光补偿、白平衡与可选景深。
- 单灯检查、曝光诊断、A/B 快照、本地方案保存；导出 PNG、JSON 和带灯位图的 HTML 布光卡。

建议先选白模与单灯预设，锁住曝光，再改变一项灯位或尺寸。比起皮肤质感，白模更容易观察鼻影、眼窝和颧骨上的明暗结构。

## 物理边界

采用 Three.js、three-mesh-bvh、three-gpu-pathtracer 的 GPU 路径追踪，计算面积光采样、遮挡、多次反射与 GGX 表面反射。它适合练习布光结构；**还不能作为现实闪灯功率或真人肤质的精确预测器**。

- 功率以一个参考灯的 **1000 lm / 0 EV** 为起点，相对档位每增加 1 EV，总光通量翻倍。这不是 AD200Pro 的 Ws，也不是灯具的 1/1、1/16 输出刻度；尚无实测灯具配光、柔光箱损耗、格栅或蜂巢模型。
- 光圈 / ISO / 快门遵循**连续光曝光关系**。快门控制不能直接照搬到同步速度以内的闪光摄影；应固定快门比较布光。
- 男性头部保留扫描几何与贴图；三个角色使用用户提供的原始 MMD 几何与贴图。皮肤均使用表面材质，没有完整皮下散射、独立眼球角膜折射、细发散射与真实服装织物。扫描贴图可能带有采集时残留的明暗。
- 色温、色调、白平衡使用线性 RGB 近似，并非光谱渲染；无法预测 LED 的光谱缺口、CRI / TLCI、化妆品或布料的同色异谱。
- 曝光预览和高光诊断作用于此渲染管线，不是 Canon R7 或其他相机 RAW 的标定结果。屏幕本身也会影响观感。
- 有限采样会产生噪点，多次反射受反弹次数限制。改变灯位后需要等待重新收敛。

## 保存和迁移方案

方案存在浏览器的 `localStorage` 中；不同浏览器、无痕窗口、主机名和端口各自独立。清除浏览数据会删除存档。需要长期保留或分享的方案，请导出 JSON。

0.5 可读取 v1、v2、v3、v4 方案。v1 保留扫描人物；v2 的旧女性角色改为耀嘉音并重置姿势。新版导出为 v4，旧程序不能读取全部新字段。推荐把新版解压到新文件夹，停止旧服务后启动新版，再强制刷新页面；不要把不同版本文件混到一起。

从原托管版迁移：在原页面导出方案 JSON，再到本地版导入。两者地址不同，存档不会自动同步。`127.0.0.1` 与 `localhost` 也属于不同地址，建议始终使用启动器给出的地址。

## 如果页面没渲染出来

1. 确认地址是 `http://127.0.0.1:5273/`，启动窗口仍在运行；不要用 `file://` 打开 HTML。
2. 确认完整解压了 `dist/assets/` 与 `dist/models/`。不要混用不同发布版本的文件。
3. 试试桌面 Chrome / Edge，启用“可用时使用图形加速”，重启浏览器。驱动或设备禁用 WebGL 时，本地版仍会受到这个限制。
4. 首次编译着色器可能较慢。遇到错误时，界面会显示原因；点击“复制诊断信息”可以手动复制或下载诊断 JSON，程序不会自动发送。
5. 渲染太慢时调到草稿画质，降低采样数和反弹次数，暂时关闭景深。

端口被其他程序占用时：

```sh
python scripts/serve.py --port=5274
# 或
npm start -- --port=5274
```

不同端口的浏览器存档相互独立。人脸文件损坏时，可以重新解压发布包；开发者可运行 `npm run assets -- --force` 重新获取已注明授权的素材，再运行 `npm run build`。

## 开发

需要 Node.js 22.12+ 和 npm。依赖版本由 `package-lock.json` 锁定。

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run build
npm run check
npm start
```

Lee 扫描素材可随代码包提供；三个 MMD 角色只在个人素材目录或个人包中。只有扫描丢失或明确需要重新下载时才运行 `npm run assets`，它不会下载 MMD。下载脚本固定到 Three.js r170，并保存来源、许可与 SHA-256。它不会在正常打开页面时运行。

| 路径 | 内容 |
| --- | --- |
| `src/` | 页面、物理计算、状态、场景与渲染代码 |
| `src/assets/mmd-character.js` | 原始 PMX 加载、透明材质和骨骼适配 |
| `src/assets/characters.js` | 原始 Lee 头部扫描与棚拍道具；无旧人物生成器 |
| `src/assets/posing.js` | 两段式逆运动学、姿势预设、取景辅助 |
| `src/assets/editors.js` | 灯高图、正侧视姿势拖动 |
| `src/assets/scene-light.js` | 面积光与有限孔径光束的渲染配置 |
| `assets/LeePerrySmith/` | 原始扫描、纹理、许可与校验清单 |
| `assets/MMD/` | 个人角色素材，仅个人包包含，已加入 Git 忽略 |

`npm run package` 重建、测试和校验后，生成可分享的 `releases/cos-light-studio-source-v0.5.0.zip`，包含完整源码、预构建程序和有许可的 Lee 扫描，不包含用户的 MMD 资产。`npm run package -- --personal` 另外生成包含当前角色素材的个人本地包。个人包不能直接作为公开 Release 上传。

## 验证范围

自动检查覆盖原有光照、曝光、菲涅尔、导出、本地启动和姿势数学，以及三个真实 PMX 的几何／UV 保留、贴图文件、透明材质、材质分组、骨骼附加旋转、所有预设的手脚位置与生产路径追踪器的 BVH 构建。没有私有资产的 source 包会跳过三个模型文件检查。
